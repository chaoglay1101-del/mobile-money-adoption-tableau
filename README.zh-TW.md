# 全球南方的行動支付普及

**商業分析與 Tableau 作品集專案**

[English version](README.md)

## 專案目的

本專案分析行動支付如何改變新興市場的支付、銀行服務、儲蓄與流動性，並聚焦於撒哈拉以南非洲。分析結合 World Bank Global Findex 指標與 GSMA 行動支付市場資料，最後以互動式 Tableau Story 呈現。

## 商業問題

行動支付普及如何改變撒哈拉以南非洲的金融環境？銀行、投資人與金融科技策略團隊可以在哪些市場找到機會？

## 我完成的工作

- 使用 Python、pandas 與 Excel 清理並重整 Global Findex 資料。
- 在 Tableau 建立行動支付普及率、區域成長、傳統銀行比較、性別、年齡、匯款與儲蓄分析。
- 比較行動支付使用率、銀行帳戶持有率與數位支付行為。
- 將資料視覺化結果轉化為流動性保留、儲蓄產品、互通性與金融包容性的商業議題。
- 設計面向銀行、投資人與金融科技策略團隊的五段式 Tableau Story。

## 主要洞察

- 撒哈拉以南非洲的行動支付持續成長，但許多市場的傳統銀行帳戶持有率仍然較低。
- 在本專案的分析視圖中，肯亞、迦納與尚比亞呈現較高的行動支付普及程度。
- 行動支付改善支付可及性，但高交易使用率不一定會轉化為銀行存款或長期儲蓄。
- 銀行與金融科技業者的機會在於從單純支付服務延伸至儲蓄、流動性管理與財富管理。
- 收入、年齡與性別差異顯示，行動支付產品應採用分眾設計。

以上為描述性與探索性分析，不代表因果推論。
